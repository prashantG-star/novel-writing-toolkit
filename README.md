## ✍️ Novel & Story Writing Toolkit

कथा आणि कादंबरी लेखनाचे नियोजन सोपे आणि सुटसुटीत करण्यासाठी तयार केलेला Markdown आराखडा.

## 📂 या प्रोजेक्टमध्ये काय आहे?
* **Characters (`characters/`):** कथेतील मुख्य आणि सहाय्यक पात्रांची वैशिष्ट्ये, स्वभाव आणि पार्श्वभूमी नोंदवण्यासाठी टेम्पलेट.
* **Chapters (`chapters/`):** प्रत्येक प्रकरणातील घटनाक्रम, मुख्य दृश्ये आणि कथानकाची दिशा ठरवण्यासाठी आराखडा.

## 🚀 कसे वापरावे?
1. या रिपॉझिटरीमधील टेम्पलेट फाइल्स कॉपी करा.
2. तुमच्या नवीन कथेनुसार पात्रांची आणि प्रकरणांची माहिती भरा.
3. लेखन करताना संदर्भासाठी या नोट्स वापरा.
